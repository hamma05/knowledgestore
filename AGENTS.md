# AGENTS.md

Django bookstore project ("Knowledge Store"). Small, single dev, SQLite-backed. Frontend uses Tailwind CSS via CDN with a Knowledge Store design system.

## Layout & environment

- The repo root `D:\django mini projet\knowledgestore\` **is itself a virtualenv** (Python 3.13.9). All project code lives in the `project\` subdir — run everything from `project\`.
- Interpreter: `D:\django mini projet\knowledgestore\Scripts\python.exe`. Installed: Django 6.0.2, pillow. No `requirements.txt`, no README, no tests, no CI, no `opencode.json`.
- `.gitignore` is just `*` (auto-generated by virtualenv). Not a git repo.
- settings.py has `DEBUG=True` and a hardcoded dev `SECRET_KEY` — dev-only, fine.

## Commands (from `project\`)

- Run server: `python manage.py runserver`
- Sanity check: `python manage.py check`
- Seed DB (Arabic Islamic books): `python knowledgestore/popultatebd.py` — **not a management command**; standalone script that sets `DJANGO_SETTINGS_MODULE` itself and must run from `project\`. Idempotent (updates by title, removes duplicates). Reconfigures stdout to UTF-8 for Arabic titles — don't remove.

## Architecture

- `project/` = Django project package (settings module `project.settings`). Project-level templates live at `project\templates\` (TEMPLATES `DIRS`); project-level static at `project\static\` (`knowledgestore\images\` = book covers). SQLite DB at `project\db.sqlite3`.
- `knowledgestore/` = main app. Custom `User` (`AUTH_USER_MODEL = 'knowledgestore.User'`, adds `phone`, `address`, `code_postal`), plus `Book`, `Panier`, `Commande`, `CommandeBooks`. All views are function-based with `@login_required(login_url='login')`. After any model change: `makemigrations` + `migrate`.
- Frontend uses Tailwind CSS via CDN with the Knowledge Store design system (Playfair Display + Inter fonts, Material Symbols icons).
- `base.html` is the main template with sticky header (nav + search + cart + account), footer, and `{% block content %}` + `{% block extra_head %}` + `{% block extra_scripts %}` blocks.

## Routes

- `/` → `home` (acceuil.html — landing page with hero + featured books)
- `/shop/` → `shop` (discovery page with filters + product grid)
- `/book/<int:book_id>/` → `book_detail` (product detail page)
- `/saved-addresses/` → `saved_addresses` (account addresses)
- `/login/`, `/register/`, `/logout/` → auth views
- `/panier/<int:id>/` → cart
- `/commande/<int:id>/` → orders
- `/adresse/<int:item_id>/` → checkout address
- `/admin/` → Django admin

## Gotchas

- `Book` has **two** image fields: `image` (ImageField → `/media/books/`) and `urlimg` (static path string). Templates check `image` first, then `urlimg`, then placeholder.
- UI mixes English/French labels; DB content is Arabic.
- Cart/order routes are keyed by id (`ajouter_au_panier/<int:item_id>/`, `supprimer_du_panier/<int:item_id>/`) — keep them id-based; titles aren't unique.
- MEDIA is only served in DEBUG (`project/urls.py`).
- `base.html` cart/account links are inside `{% if request.user.is_authenticated %}` — don't put `{% url 'panier' request.user.id %}` outside that block (None causes NoReverseMatch).
- `supprimer_du_panier` only deletes the cart item (bug was fixed).
